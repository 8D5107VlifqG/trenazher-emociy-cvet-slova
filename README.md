# Тренировка эмоций

Офлайн-приложение для Android (Capacitor). Список эмоций вшит в `www/index.html`.

## Получить APK
1. Откройте вкладку **Actions** в репозитории.
2. Выберите последний запуск **Build APK** (или нажмите **Run workflow**).
3. Внизу страницы запуска в разделе **Artifacts** скачайте `trenirovka-emociy-apk`.
4. Распакуйте zip, перенесите `app-debug.apk` на телефон и установите
   (разрешите установку из неизвестных источников).

## Вкладки
«Эмоции», «Полярности» и «Арифметика» (несколько примеров на сложение и вычитание в 2–4 окнах одновременно).
Категории арифметики и число окон выбираются в настройках.

## Изменить список
Эмоции лежат в `www/index.html` в переменной `DEFAULT_ITEMS`.
После правки сделайте commit: APK пересоберётся сам.

## Какие Android поддерживаются
Минимум Android 5.1 (API 22), то есть Android 6 тоже подходит. В логе сборки шаг
«Show minimum Android version of the APK» печатает итоговый `sdkVersion`.
На старых телефонах также должен быть обновлён «Android System WebView» (версия 60 и новее)
через Google Play.
